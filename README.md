# daylobby

A quiet, horizontally draggable calendar for deciding what to do today. The interface is a simplified reconstruction of the interaction model at [senyil.com/what-should-we-do-today](https://senyil.com/what-should-we-do-today/), using flat color cards in place of event artwork and omitting the filter control.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Build the production bundle with `npm run build`.

## Interaction

- Drag or swipe horizontally to move between About, Today, This week, This month, and This year.
- Use Arrow Left, Arrow Right, Home, and End for keyboard navigation.
- Open any card for its details. Press Escape or click outside the tray to close it.
- On mobile, swipe horizontally to move between the About panel and each period.
